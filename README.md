# writejs.io

A zero-dependency JS playground: write JavaScript on the left, see console output on the right. Plain HTML/CSS/JS — open `index.html` and go.

## Features

- **⌘S** — format with Prettier (vendored, works offline); toggleable in the header
- **⌘↩** — run in a fresh sandboxed iframe; logs, errors, rejections, and the last expression value land in the console pane
- **⌘/** — toggle comments (line or selection)
- **⌘D** — select word, then all occurrences; typing edits all of them at once
- 11 color themes, draggable split, code persisted in localStorage
